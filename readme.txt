Seamless channel management, dynamic pricing, and reservation sync engine connecting Beds24 and PMS channels to the Homey WordPress Theme.

== Description ==

Homey Channel Sync connects the Homey Booking Theme with Property Management Systems (PMS) like Beds24 to enable automated dynamic daily pricing, rate syncs, and real-time reservation management.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/homey-channel-sync` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Configure settings on the Homey Channel Sync page under Settings.
